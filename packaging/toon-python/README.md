# toon-python

This package is an alias. It contains no code and installs
[`toon-format`](https://pypi.org/project/toon-format/), the official Python
implementation of [TOON](https://github.com/toon-format/spec):

```bash
pip install toon-format
```

Use `toon-format` in new projects. Documentation and issues live in the
[toon-python repository](https://github.com/toon-format/toon-python).
