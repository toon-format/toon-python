# toon-format

`toon-format` is the former name of
[`toon-python`](https://pypi.org/project/toon-python/), the official Python
implementation of [TOON](https://github.com/toon-format/spec). Installing it
installs `toon-python` and the deprecated `toon_format` module of the 0.9 API.
New projects should depend on `toon-python`:

```bash
pip install toon-python
```

Documentation and issues live in the
[toon-python repository](https://github.com/toon-format/toon-python).
